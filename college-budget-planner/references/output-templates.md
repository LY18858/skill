# 输出模板与素材库

## 一、通用写作口径

- 第一行先给**一句结论**：这个月能不能存下钱、大额支出是否可行。
- 不寒暄、不加结尾套话、不做无关科普。
- 每个板块 1–2 句：金额 + 一句依据，不写套话。
- 省钱建议 4–6 条，避雷提醒 3–5 条，**按用户情况挑选，不是全量罗列**。
- 金额一律取整到 10 元，与脚本输出完全一致，**一个字都不要改**。

## 二、五段模板

```markdown
{一句结论}

## 1. 月度生活费分配方案

- **三餐伙食 XXX 元**：{按 N 天、每天 X 元说明，强调这是底线}
- **日常零碎 XXX 元**：{洗漱、纸巾、文具、打印}
- **娱乐社交 XXX 元**：{折合成几次聚餐 / 几杯奶茶}
- **储蓄 XXX 元**：{月初转出、现金或活期、当月不动}
- **应急备用金 XXX 元**：{餐饮超支补位、买药、电费补缴；占 R 的 X%}

## 2. 预算明细表

| 项目 | 每月金额 | 占生活费 | 备注 |
|---|---|---|---|
| 固定开销（或拆分） | X | X.X% | 话费 40 + 交通 50 + … |
| 宿舍杂费（小程序） | X | X.X% | {季节}定额：洗澡 X / 饮水 X / 洗衣 X / 电费 X |
| 三餐伙食 | X | X.X% | N 天 × X 元/天 |
| 日常零碎 | X | X.X% | … |
| 娱乐社交 | X | X.X% | … |
| 储蓄 | X | X.X% | … |
| 应急备用金 | X | X.X% | … |
| 本月大额：{名称} | X | X.X% | 一次性支出 |
| **合计** | **X** | **100.0%** | 占比四舍五入，合计按 100% 计 |

## 3. 大额支出调整方案

{不触发时：一句话说明固定开销+大额占比远低于 70%，按方案执行即可，不要留空}
{触发时：先说触发原因，再给 2–3 套方案，每套写明：砍什么、省多少、代价是什么}

## 4. 校园省钱建议

{4–6 条，从下方素材库按场景挑选}

## 5. 消费避雷提醒

{3–5 条，从下方素材库按用户风险点挑选}
```

## 三、大额支出取舍方案骨架

按优先级 **保吃饭 > 保刚需 > 保储蓄（≥5%）> 砍娱乐 > 砍日常零碎** 排列，每套都要有代价：

```markdown
**方案 A：{照买 / 推迟 / 降配}**
{从哪几块各挪多少，凑出这笔钱}
代价：{哪块被牺牲到什么程度}
```

优先给出「推迟到下月」「买二手」「降配」「和舍友拼单」这类替代路径，
**禁止**提分期、借贷、花呗周转。

## 四、复盘模式模板

用户说「超支了 / 帮我复盘 / 我花了多少」时启用，先确认 3 个数字（缺则问）：
本月实际总支出、超支最严重的板块、本月是否发生大额消费。

```markdown
## 一句话
{超支多少，主要超在哪}

## 超支拆解
{超支金额与板块占比，用用户给的实际数字，不给就说明按估算}

## 归因
{哪类支出失控：单价高 / 频次高 / 一次性大额；不指责}

## 下月两条调整
1. {具体到金额的动作}
2. {具体到金额的动作}

{一句鼓励，不写「下次别再犯」这类空话}
```

## 五、省钱建议素材库（每次挑 4–6 条）

| 场景 | 内容 | 适用 |
|------|------|------|
| 食堂 | 基础窗口比特色窗口每餐便宜 3–5 元，月省 80–120 元 | 所有预算 |
| 食堂 | 错峰就餐、按需打饭减少浪费 | 预算偏紧 |
| 二手 | 教材、考研资料、小电器、自行车、手表走校园二手群/跳蚤市场 | 有大额或开学季 |
| 拼单 | 日用品按箱买再和舍友分摊，单价约为超市六到七成 | 长期 |
| 免费资源 | 图书馆自习位（顺带省宿舍电费）、学校正版软件与教育版优惠 | 所有预算 |
| 硬省钱 | 学生交通卡、影票优惠、校园周边的学生价 | 有出行娱乐 |
| 网购 | 凑单先算账：为凑满减多买 60 元不需要的东西，实际是亏的 | 爱网购 |
| 支付隔离 | 三餐预算单独放一个余额，与娱乐分开 | 全线上支付环境 |
| 定额充值 | 宿舍三费在小程序月初一次充够，不要 5 元一充 | 全线上支付环境 |

## 六、避雷素材库（每次挑 3–5 条）

| 陷阱 | 提醒要点 |
|------|----------|
| 冲动网购 | 凑单/限时秒杀最容易买回用不上的东西，购物车放三天再决定 |
| 频繁外卖 | 一餐 15–25 元是食堂两倍，每周多 3 次一月多出约 200 元 |
| 盲盒与抽卡 | 单次金额小、频次高，月底对账最易漏，设月度上限 |
| 奶茶与聚餐 | 单次 8–80 元，风险在频次不在单价，翻账单先看次数 |
| 预付卡会员推销 | 校园内推销的健身卡、理发卡、会员充值，办卡容易退卡难 |
| 宿舍电费 | 空调长开、私接大功率电器，是月底突然被收 100+ 的主因 |
| 线上支付无感 | 微信/支付宝一笔过，多个小程序各充各的，没有余额提醒，建议每周翻账单、月中统一查余额 |
